30-Day Python → AI Journey

A public, hands-on learning path designed to turn Python fundamentals into practical software engineering and entry-level AI/ML capability.

PythonGit & GitHubNumPyPandasscikit-learnFastAPI

Goal

Build Python fluency through daily coding, then connect it to software-engineering practices, data handling, machine learning and API development.

Approach

Learn → code from memory → solve small problems → commit progress → gradually increase project complexity.

Roadmap

  • Python syntax, control flow, collections and functions.
  • Files, errors, OOP, packages, virtual environments and Git.
  • NumPy, Pandas, data cleaning and visualization.
  • Machine-learning concepts, scikit-learn and evaluation.
  • REST APIs, FastAPI, SQL, testing and Docker foundations.

Live repository

The repository is intentionally public so progress can be inspected through real commits instead of a static skill claim.
